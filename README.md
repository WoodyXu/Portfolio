# 投资组合跟踪小程序

## 项目简介

这是一个专门为个人投资者设计的微信小程序，用于跟踪和管理投资组合。它提供了直观的界面，帮助用户实时监控投资标的、查看资产分布、记录交易历史，并提供全面的数据管理功能。

## 主要功能

### 1. 投资组合总览
- 显示投资组合总金额
- 显示最新更新时间
- 提供"展开详情"按钮，一键展开所有资产分类
- 支持查看全展开的资产分布信息

### 2. 资产分布
- 按一级分类和二级分类展示资产分布
- 每个分类显示金额和占比
- 支持一级分类和二级分类的展开/折叠
- 显示投资标的的详细信息，包括数量、价格、金额和占比

### 3. 交易功能
- **买入操作**：添加新的投资标的或增加现有标的的持有数量
- **卖出操作**：减少现有标的的持有数量或完全卖出
- **更新操作**：更新投资标的的价格和分类信息

### 4. 交易记录
- 显示所有交易记录
- 支持按买入、卖出、更新操作进行筛选
- 显示交易日期、数量、价格、金额等详细信息

### 5. 数据管理
- 支持数据的导入和导出
- 提供数据备份和恢复功能
- 支持清除所有数据（谨慎使用）

## 技术架构

### 前端技术
- 微信小程序原生开发
- 使用微信小程序的视图层、逻辑层和网络层
- 实现了响应式设计，适配不同尺寸的设备

### 数据存储
- 使用微信小程序的本地存储API
- 投资组合数据和交易记录存储在本地
- 支持数据的导入和导出

### 计算引擎
- 实现了资产分布计算算法
- 支持按一级分类、二级分类和投资标的计算占比
- 提供实时的资产价值计算

## 使用说明

### 1. 启动程序
- 打开微信小程序
- 点击"投资组合跟踪"小程序图标

### 2. 添加投资标的
- 点击首页的"买入"按钮
- 填写标的代码、名称、数量、价格等信息
- 选择所属投资品种分类
- 点击"确认买入"按钮

### 3. 查看资产分布
- 在首页查看资产分布图表
- 点击分类名称展开查看详情
- 点击"展开详情"按钮查看全展开的资产分布

### 4. 记录交易
- 每次买入、卖出或更新操作都会自动记录
- 在"交易记录"页面查看所有记录
- 使用筛选功能快速找到需要的记录

### 5. 数据管理
- 在"设置"页面进行数据管理
- 点击"导出数据"备份数据
- 点击"导入数据"恢复数据
- 点击"清除所有数据"重置程序（谨慎使用）
